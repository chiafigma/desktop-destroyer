# Attribution and provenance

This is an unofficial fan port. **None of the artwork or audio in this repository is ours.**

## The original

**Desktop Destroyer** — the 1990s freeware stress-reliever, also circulated as Desktop
Games, Stress Reducer, Stress Relief, The Stress Game and Desktop Killer.

- **Original design:** Miroslav Němeček
- **Source:** <http://www.gemtree.com/program.htm>

## The rip we use

The sprites and sounds are not taken from the original executable. They come from the
[windows93.net](https://windows93.net) recreation:

- **Sprite ripping:** Jankenpopp & Zombectro
- **Recreation code:** Zombectro
- **Asset origin:** `https://windows93.net/c/programs/misc/DesktopDestroyer/assets`

No licence accompanies any of this material. The original is freeware; the rip carries no
stated terms.

## What's vendored where

| Path | What it is | In the build? |
| --- | --- | --- |
| `ref/w93/` | The windows93 rip, one directory per weapon — 107 PNG and OGG files. The canonical set. | **Yes** — every sprite and sound is inlined from here |
| `ref/windows93/` | An earlier copy of the same rip, 104 files. 102 are byte-identical to `ref/w93/`. | No |
| `ref/sprites/`, `ref/sounds/` | An older rip with `.webm` audio, from a different third-party reimplementation. Superseded. | No — see [assets.md](assets.md#what-happened-to-sheets-and-sounds) |
| `ref/src/` | Weapon and sprite configs in TypeScript from that same reimplementation. | No |
| `desktop-destroyer-ref/` | The windows93 app itself. The authority for upstream weapon tuning, cited by name in `src/shared/weapons/`. | No |
| `assets/icons-src/`, `assets/icons/`, `assets/cursors/` | Menu icons. **Ours**, generated by `npm run assets`. | `assets/icons/` only |
| `cover.png` | Plugin cover art. Ours. | No |

`ref/windows93/` is redundant with `ref/w93/` and could go, with one caveat: it holds
`2-machine-gun/press.png` and `4-color-thrower/press.png`, which `ref/w93/` does not.
`ref/w93/` has five sounds it lacks in return.

## Licensing

No `LICENSE`, deliberately: we can't license work that isn't ours to license, and the
vendored assets have no stated terms. The repo is private.

Nothing structural depends on these specific PNGs — sprite geometry is declared per weapon
and verified against whatever files are on disk, so replacement art would drop straight in.
